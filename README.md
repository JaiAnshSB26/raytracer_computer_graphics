Covers Lab 1 - 4 of the Computer Graphics course.

For the brevity of things, I am going to keep the final README super concise!

There are 2 main files in this repository:

1. `main.cpp` - This is my main file, it contains everything except the last optional texture part and the random old (not in use anymore) code or some comments I tend to leave for myself when programming in any lower level language to be careful!

2. `main_optional.cpp` - This is the file which contains every functional element + the final optional texture part as well, I brought in this file (formed by copying my main file and doing the modifications) since I had to revert to one of my previous `main.cpp` versions after I ran into too many bugs with my initial attempt to edit/upgrade the functions in main.cpp, so for the versioning I separated out main.cpp and completed the texture part here instead. Unfortunately due to lack of time, I couldn't clean out the junk code and self-notes from this file, but it works perfectly well functionally too!

Please also note that to maintain the history of the images I experimented around with, I have maintained a `images_archive/` directory! (with some images in the root.)
